Reference Banners Boosts accuracy ~25%

Reference banners live permanently in your GitHub repo — loaded automatically every session. To add more: upload JPG/PNG files to banner-portal/references/ in GitHub and add the filename to references/manifest.json.

How to add references permanently:
1. Go to github.com/Leons45/Webs → banner-portal/references/
2. Upload your banner JPG/PNG files
3. Edit manifest.json and add the filenames to the array
4. Reload this portal — they load automatically every session

Variants to Generate

Each variant uses different visual psychology. All 3 are generated for every template+size combo.

⚡ Bold
Maximum visual impact. High contrast, big type, dominant yellow. Loss-aversion framing (SAVE $X). Best for urgent sales.
✦ Clean
Breathable whitespace. Price-anchored layout (reg/sale). Sophisticated and readable. Best for premium products.
◈ Dramatic
Dark mood, gradient depth, lifestyle energy. Aspirational with bold CTA. Best for seasonal events & brand moments.
